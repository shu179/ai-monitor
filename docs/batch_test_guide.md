# 批量测试功能使用说明

## 功能概述

批量测试功能用于统计品牌在多个 AI 平台上的展示率，并分析媒体来源的抓取情况。

## 功能特点

- **多关键词 × 多平台 × 多次查询**：支持配置多个关键词，每个关键词可选择不同的平台和查询次数
- **实时进度显示**：测试过程中实时显示当前进度和执行状态
- **详细报告分析**：
  - 品牌展示率统计（总体、关键词维度、平台维度）
  - 跨平台同抓取媒体分析
  - 跨关键词相同媒体分析
  - 全局媒体矩阵（关键词×平台）

## 使用步骤

### 1. 启动 Web UI

```bash
python web_desktop.py
```

### 2. 进入「发稿」页面

在左侧导航栏点击「发稿」图标。

### 3. 点击「品牌分析」按钮

在页面右上角点击「品牌分析」按钮，打开批量测试配置对话框。

### 4. 配置测试参数

#### 品牌名称
输入要测试的品牌名称，例如：「华为」

#### 关键词配置
- 点击「添加关键词」可添加多个关键词
- 每个关键词可以配置：
  - **关键词**：搜索关键词，例如「手机推荐」
  - **查询次数**：该关键词在每个平台上的查询次数（1-50次）
  - **选择平台**：勾选要测试的平台（豆包、DeepSeek、Kimi、元宝、通义、文心）

#### 配置示例

```
品牌名称: 华为

关键词1:
  关键词: 手机推荐
  查询次数: 10
  平台: ☑ 豆包  ☑ DeepSeek  ☑ Kimi

关键词2:
  关键词: 旗舰手机
  查询次数: 5
  平台: ☑ 豆包  ☑ 通义
```

### 5. 启动测试

点击「启动测试」按钮，系统会：
1. 生成查询计划（按关键词顺序，每个关键词内按平台顺序）
2. 显示进度对话框，实时更新执行状态
3. 可随时点击「取消测试」中断执行

### 6. 查看报告

测试完成后自动显示报告对话框，包含三个维度的分析：

#### 关键词维度
- 每个关键词的总体展示率
- 各平台的展示率对比
- 跨平台同抓取媒体（出现在≥2个平台的媒体）

#### 平台维度
- 每个平台的总体展示率
- 跨关键词相同媒体（出现在≥2个关键词的媒体）

#### 媒体矩阵
- 全局跨关键词跨平台的媒体分布
- 每个媒体在各关键词×平台组合中的出现次数和比例

## 技术实现

### 后端模块

- **core/batch_test_runner.py**：批量测试执行器
  - 构建查询计划
  - 顺序执行查询（避免并发导致的反爬检测）
  - 记录结果到 history
  - 支持取消操作

- **core/batch_test_report.py**：报告生成器
  - 从 history 读取批量测试记录
  - 计算品牌展示率统计
  - 分析跨平台/跨关键词媒体

- **web_backend.py**：API 端点
  - `POST /api/batch-test/start`：启动批量测试
  - `GET /api/batch-test/{batch_id}/progress`：获取进度
  - `GET /api/batch-test/{batch_id}/report`：获取报告
  - `POST /api/batch-test/{batch_id}/cancel`：取消测试

### 前端组件

- **BatchTestDialog.tsx**：配置对话框
- **BatchTestProgressDialog.tsx**：进度对话框
- **BatchTestReportDialog.tsx**：报告对话框
- **ReleaseContent.tsx**：集成入口

## 数据存储

- **批量测试配置**：`user_data/batch_tests/{batch_id}.json`
- **测试报告**：`user_data/batch_tests/{batch_id}_report.json`
- **查询记录**：存储在 `history/` 目录，通过 `extra.batch_id` 关联

## 注意事项

1. **查询间隔**：每次查询之间有 1 秒延迟，避免请求过快
2. **浏览器模式**：批量测试默认使用 browser 模式，需要确保平台认证已完成
3. **测试时长**：根据配置的关键词数、平台数和查询次数，测试可能需要较长时间
4. **取消操作**：取消后当前查询会完成，但不会继续后续查询
