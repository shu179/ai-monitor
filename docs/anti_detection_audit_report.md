# 反检测系统审查报告

**审查日期**: 2026-04-21  
**目标场景**: 中国AI平台网页版长期自动化使用（豆包、DeepSeek、Kimi、元宝、通义千问、文心一言）  
**核心目标**: 被平台识别为持续正常使用的真实用户

## 一、当前反检测架构评估

### ✅ 优势部分

1. **基础架构合理**
   - 使用 Patchright（CDP层反检测）替代 playwright + playwright-stealth
   - persistent_context 模式保持登录状态和浏览历史
   - 稳定指纹配置（BrowserFingerprint）确保长期一致性

2. **行为模拟完善**
   - 人类输入模拟：随机延迟（80-180ms）、思考停顿（15%概率）
   - 鼠标轨迹模拟：贝塞尔曲线、随机抖动
   - 多种行为模式：quick_scan、careful_read、direct_action、idle_browse
   - 浏览器存储预热：LocalStorage/SessionStorage 模拟老用户

3. **JS注入策略轻量**
   - 只覆盖关键检测点（navigator.webdriver、window.chrome）
   - Canvas/Audio 轻微噪声注入（0.1%概率）
   - 避免过度伪造（保留真实浏览器API）

### ⚠️ 风险点与修复

#### 1. **启动参数策略调整**（已修复）

**问题**: 原计划禁用 WebGL/WebRTC，但中国AI平台可能依赖这些功能
- WebGL: 图表渲染、可视化（通义千问、Kimi 的数据展示）
- WebRTC: 语音输入、实时通信（豆包、文心一言的语音功能）

**修复**: 
- 移除 `--disable-webgl/--disable-webgl2/--disable-webrtc`
- 保留 WebRTC 但优先使用 relay 模式（JS层轻量防护）
- 保留 navigator.connection/getBattery API（真实浏览器有）

#### 2. **指纹配置合理性**（已修复）

**问题**: 内存配置与CPU核心数不匹配
- 8核配 8-16GB（偏低，真实高端设备通常 16-32GB）
- 16核配 16-32GB（偏低，真实工作站通常 32-64GB）

**修复**:
- 8核 → 16-32GB
- 16核 → 32-64GB

#### 3. **JS注入去重**（已修复）

**问题**: 
- navigator.webdriver 覆盖重复（#1 和 #13）
- permissions.query 覆盖重复（#3 和 #12）

**修复**: 移除重复注入，保留更完善的版本

## 二、针对中国AI平台的特殊考量

### 1. **平台检测特点**

中国AI平台的反爬策略通常包括：
- **行为分析**: 输入速度、鼠标轨迹、停顿时间
- **频率限制**: 短时间内大量请求
- **设备指纹**: User-Agent、Canvas、WebGL、硬件信息
- **验证码**: 滑动验证、点选验证（豆包、百度）
- **账号关联**: 多账号使用相同指纹会被关联

### 2. **当前程序的应对策略**

✅ **已实现**:
- 随机间隔调度（SmartScheduler）
- 30分钟去重（WeComNotifier cooldown）
- 每个平台独立 user_data_dir（避免账号关联）
- 稳定指纹配置（每个账号长期一致）
- 人类行为模拟（输入、鼠标、滚动）
- 人工干预机制（检测到验证码自动暂停）

✅ **优化建议**:
1. **输入延迟增强**: 当前 80-180ms，建议增加到 100-250ms（更接近真人）
2. **查询间隔**: 确保每个平台至少间隔 5-10 分钟（避免频率检测）
3. **错误重试**: 当前最大5次，建议降低到3次（避免短时间内重复失败）
4. **浏览器版本**: 定期更新 Chrome 版本号（当前147，需跟随真实版本）

## 三、长期使用风险评估

### 低风险 ✅
- **设备指纹稳定**: 每个账号使用独立且稳定的指纹配置
- **行为模式多样**: 4种行为模式随机切换，避免固定套路
- **登录状态持久**: persistent_context 保持 Cookie/LocalStorage
- **人工干预机制**: 检测到异常自动暂停，避免触发封号

### 中风险 ⚠️
- **查询频率**: 如果配置不当（间隔过短），可能触发频率限制
- **关键词重复**: 长期使用相同关键词可能被识别为机器人
- **浏览器版本**: Chrome 147 是2026年4月版本，需定期更新
