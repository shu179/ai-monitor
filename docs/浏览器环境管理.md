# 浏览器环境管理

## 问题背景

AI 平台（如豆包）会检测自动化工具，当浏览器上下文积累了太多自动化特征后，会被限流或封禁。

**症状：**
- 正常浏览器可以访问，但程序里登录后显示异常
- 被限流、验证码频繁出现
- 账号被标记为风险账号

**原因：**
- 持久化浏览器上下文（user_data/auth 目录）积累了检测特征
- CDP 连接痕迹、异常行为模式被平台识别

## 解决方案

### 方案一：重置单个平台（推荐）

当某个平台出现问题时，只重置该平台：

```bash
# 交互式选择
python3 reset_browser_env.py

# 直接指定平台
python3 reset_browser_env.py doubao
python3 reset_browser_env.py deepseek
python3 reset_browser_env.py kimi
```

### 方案二：重置所有平台

当多个平台都出现问题，或想彻底清理时：

```bash
python3 reset_browser_env.py --all
```

### 方案三：查看当前状态

查看各平台的环境状态和路径：

```bash
python3 reset_browser_env.py --list
```

## 重置后的步骤

1. **重启程序** - 让程序加载新的浏览器环境
2. **重新登录** - 在程序的「平台账号」菜单中，点击对应平台重新登录
3. **测试** - 运行一次任务，确认不再被限流

## 目录结构说明

程序使用三种路径存储浏览器数据：

### 1. 旧版路径（legacy）
```
auth/
├── doubao/      # 豆包旧环境
├── deepseek/    # DeepSeek旧环境
├── kimi/        # Kimi旧环境
└── ...
```

### 2. 新版路径（fresh）
```
user_data/browser_auth_profiles/
├── doubao/
│   └── profile-xxxxx/    # 独立的豆包环境
├── deepseek/
│   └── profile-xxxxx/    # 独立的DeepSeek环境
└── ...
```

### 3. 共享路径（已废弃）
```
user_data/          # 早期版本豆包使用的共享目录
├── Default/
├── Cookies
└── ...
```

**重置逻辑：**
- `reset_browser_env.py` 会自动检测并清理所有相关路径
- 清理后创建全新的独立环境（新版路径）
- 不同平台的环境完全隔离，互不影响

## 技术细节

### 清理范围

单个平台重置会清理：
1. 该平台所有已注册的 profile 目录
2. `user_data/browser_auth_profiles/{platform}/` 目录
3. `auth/{platform}/` 目录
4. 如果该平台使用了共享 `user_data/`，也会清理

全平台重置会清理：
1. 整个 `user_data/` 目录
2. 整个 `auth/` 目录
3. `user_data/browser_auth_profiles.json` 配置文件

### 代码位置

- **核心逻辑**: `core/browser_auth.py`
  - `reset_browser_auth_environment()` - 重置单个平台
  - `reset_all_browser_auth_environments()` - 重置所有平台
  
- **命令行工具**: `reset_browser_env.py`
  - 提供交互式界面和命令行参数

## 预防措施

1. **降低任务频率** - 避免过于频繁的自动化操作
2. **增加随机延迟** - 程序已内置，但可以调大
3. **定期轮换环境** - 每隔一段时间重置一次环境
4. **使用多账号** - 不同任务使用不同账号

## 常见问题

### Q: 重置后会丢失什么？
A: 只会丢失浏览器登录状态和 Cookies，不会影响任务配置和历史记录。

### Q: 需要停止程序吗？
A: 建议停止程序后再重置，避免文件占用冲突。

### Q: 重置后还是被限流怎么办？
A: 可能是账号本身被标记，建议：
   1. 换个账号
   2. 等待一段时间（24小时）
   3. 联系平台客服

### Q: 可以手动删除目录吗？
A: 可以，但建议用脚本，因为：
   1. 脚本会自动处理所有相关路径
   2. 会更新配置文件
   3. 会创建新的干净环境
